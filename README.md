## 🆕 Atividade E2 — CRUD em Java com SQLite

📁 **Código completo da atividade E2:**  
`navio_crud/navio_crud`

### 📌 Descrição  
Atividade prática envolvendo a implementação de um sistema **CRUD completo em Java**, utilizando:

- JDBC (com driver SQLite)  
- Banco de dados SQLite integrado ao projeto  
- Operações de criar, consultar, atualizar e excluir registros  
- Estrutura organizada em DAO, Model e Interface

Inclui todos os arquivos necessários:  
- Código `.java`  
- Banco `banco.db`  
- Driver SQLite JDBC configurado  

Essa atividade demonstra o uso de banco de dados local integrado a um sistema Java, seguindo boas práticas de arquitetura.
